# サンプル冊子 — pdf-booklet 記法見本

バージョン 1.0

この冊子は、Markdown 原稿がどのように組版されるかを示すサンプルです。

## 第1章 基本の記法

原稿は通常の Markdown として書きます。見出しや箇条書きといった標準的な記法はそのまま使えますが、いくつかの決まった書き方を使うと、エンジンがその意味を読み取って冊子向けの体裁に変換します。この章では、文章の骨格をつくる基本的な記法を扱います。

### Q1. 章はどのように作りますか

`## 第n章 ◯◯` という見出しを書くと、その位置に章扉が生成されます。章番号が大きく表示され、章ごとに異なるアクセントカラーが自動で割り当てられます。

色はテンプレート側のパレット定義から順番に取られるため、原稿に色を書く必要はありません。モノクロ印刷向けのテンプレートでは、パレットをすべて黒に設定することで同じ原稿がそのまま単色で組まれます。

### Q2. 用語の説明はどう書きますか

箇条書きの項目を `**用語**: 説明` の形で書くと、用語部分で改行した2行構成に変換されます。用語集や一覧の可読性が上がります。

- **章扉**: `## 第n章 ◯◯` で生成される、章の区切りとなるページ
- **Qバッジ**: `### Qn. ◯◯` と書いた見出しに付く、番号入りのバッジ
- **ノンブル**: ページ番号のこと。体裁はテンプレート側の設定で指定する

### Q3. 表はそのまま書けますか

通常の Markdown の表記法で書けます。ヘッダ行には章のアクセントカラーが適用され、角丸のカードとして描画されます。

| 原稿の書き方 | 変換結果 |
|---|---|
| `# タイトル — サブタイトル` | 表紙 |
| `## 第n章 ◯◯` | 章扉 |
| `### Qn. ◯◯` | Qバッジ付き見出し |
| `### コラム: ◯◯` | COLUMN カード |
| `ヒント: ◯◯` | HINT カード |

表やカードは途中で分割されず、常に丸ごと1ページに収まるよう改ページされます。そのため極端に長い表を作ると、直前のページに大きな余白ができることがあります。目安として、ひとつのカードが A4 の半分以内に収まる分量を意識して書くと安定します。

**第1章 この章で覚えること**

- 章扉は `## 第n章` で生成され、色は自動で割り当てられる
- `**用語**: 説明` は2行構成に変換される
- 表とカードは分割されず、1ページに丸ごと収まる

## 第2章 カードと装飾

基本の記法に加えて、読み手の注意を引くための装飾がいくつか用意されています。いずれも原稿側では特別なタグを書かず、決まった書き出しの段落として表現します。原稿を素の Markdown として読んでも意味が通るようにするための設計です。

### コラム: なぜテンプレートを分けるのか

PDF を直接生成させると、レイアウトやデザインの細部まで意図どおりに制御するのが難しくなります。そこで、Markdown の解釈とページネーションを共通のエンジンに任せ、テンプレート側は見た目だけを持つ構成にしています。

同じ原稿から、カラーの学習ガイド風にも、モノクロ印刷向けの zine 風にも書き出せるのはこの分離によるものです。

ヒント: 新しいテンプレートを作るときは、既存のテンプレートをコピーするのではなく、HTML の契約仕様を読んでから設計してください。エンジンが出力するクラス名が決まっているため、そこさえ押さえれば見た目は自由に決められます。

### Q4. 書き方の注意点はありますか

引用の中で `NG:` `OK:` から始まる行を書くと、バッジ付きで対比表示されます。悪い例と良い例を並べるときに使います。

> NG: 短い1文だけの段落を、要点整理カードの直前に置く。
>
> OK: 章末の最後の段落は、3行以上のまとまった文章にする。

覚え方: 迷ったら「カードは分割されない」と考える

装飾は多用すると効果が薄れます。1ページに複数のカードが並ぶと、どれが重要なのか読み手に伝わらなくなるためです。強調したい箇所を絞り込み、地の文で説明できることは地の文で書くほうが、結果として読みやすい冊子になります。

**第2章 この章で覚えること**

- 装飾は特別なタグではなく、決まった書き出しの段落で表現する
- `NG:` `OK:` は引用の中に書くと対比表示になる
- カードを多用すると強調の効果が薄れる

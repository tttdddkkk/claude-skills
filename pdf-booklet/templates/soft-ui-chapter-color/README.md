# ソフトUI × 章カラー制

明朝ディスプレイ体のタイトル、章ごとに変わるアクセントカラー、ソフトグレー地にカード型レイアウトの冊子デザイン。Q&A形式の学習資料・入門ガイド向け。

## 構成
- `style.css` — デザイン定義(ソフトグレー地・カード・章カラーパレット・明朝ディスプレイ)
- `template.json` — テンプレート名・説明・章カラーパレット(章の登場順に循環適用)

Markdownの解釈ルール(章扉・Q&A・POINT/HINT/COLUMNカードなどへの変換)は全テンプレート共通で `../../lib/engine.py` が担う。このテンプレートは見た目(CSS)とパレットのみを定義する。共通の変換ルール一覧は `../../SKILL.md` を参照。

## カスタマイズ
- 章カラーを変えたい場合は `template.json` の `palette` 配列を編集
- 地色・影・フォントは `style.css` 冒頭の `:root` 変数で一括変更
- 日本語フォントは Noto Sans CJK JP / Noto Serif CJK JP があれば使用される(未インストールの場合はシステムフォールバックフォントで代替されるが、行間・折り返しが環境依存になる点に注意)

## 既知の注意点
グラデーション文字(`background-clip: text`)やぼかし付き`box-shadow`は、ヘッドレスChromiumのPDF書き出しで枠線状のアーティファクトが出ることがあるため、このテンプレートでは使用していない(単色文字+実線ボーダーで統一)。新しいテンプレートを作る際もこの制約に注意すること。

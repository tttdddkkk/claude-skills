# stencil-mono — ステンシル / リソグラフ風モノクロ

同人誌・zine のモノクロ印刷入稿を想定したテンプレート。使用色は黒(#000)と紙白のみ。

## 設計の前提

- **A4出力を A5 に2面付けする前提**で組んである。本文13pt は A5 に縮小(70.7%)されると約9.2pt になる。A4のまま読ませる用途では文字が大きすぎるので、`body { font-size }` を 10pt 前後に下げる
- 章ごとの区別は色ではなく**巨大な章番号**(`.ch-no` 64pt)で行う。`palette` は全章 `#000000` で統一してある
- ぼかしを一切使わない。カードの立体感は「ぼかし0の box-shadow(版ズレ風オフセット)」と実線ボーダーで出している

## 最初に触るとよい変数

`style.css` 冒頭の `:root` に集約してある。

| 変数 | 役割 | 備考 |
|---|---|---|
| `--misreg` | 版ズレ風オフセットの量 | `0mm` にすると平面的な仕上がりになる |
| `--rule` / `--rule-bold` / `--rule-thin` | 罫線の太さ | 冊子全体の印象を最も左右する |
| `--tint` | 表紙のハーフトーン網点の濃さ | 2値入稿で網点化を避けたい場合は `#FFFFFF` に |
| `body { font-size }` | 本文サイズ | 面付けしない場合はここを下げる |

表紙の網点そのものを消すには、`.cover` の `background-image` / `background-size` の2行を削除する。

## モノクロ特有の設計判断

- **NG / OK の区別**: 色が使えないため、バッジをベタ黒(NG)と白抜き枠(OK)に振り分け、さらに左罫線を実線/二重線で変えている。`double` は 1mm 未満だと実線と区別が付かないため `--rule-bold` を使っている
- **表**: ヘッダをベタ黒+白抜きにし、行の塗り分け(ゼブラ)は使っていない。2値入稿で網点化されるのを避けるため
- **グレーの使用**: 表紙の網点(`--tint`)以外では使っていない

## 既知の制約(テンプレートでは解決できない)

いずれも `lib/engine.py` 側の実装に由来する。変更するには engine の改修が必要で、既存テンプレートにも影響する。

- **判型はA4固定** (`format="A4"`)。A5 で直接出力することはできない
- **ノド(綴じ側)を広げる非対称マージンは不可**。JSによる疑似ページネーション方式のため `@page :left/:right` が効かない
- **塗り足し3mm・トンボは出力されない**

## ノンブル(ページ番号)

PDFのフッター領域に描画されるため `style.css` では変更できない。`template.json` の `nombre` で指定する(engine の既定値は 7pt / `#7A8194` / 右寄せ / `{page} / {total}`)。

本テンプレートでは、面付け時の縮小を見込んで **12pt・黒・中央寄せ**、表記は**ページ番号のみ**、**表紙にはノンブルを入れない**設定にしてある。

```json
"nombre": {
  "font_size": "12pt",
  "color": "#000000",
  "align": "center",
  "format": "{page}",
  "skip_cover": true
}
```

中央寄せは見開きで左右対称になるため中綴じと相性がよい。左右交互(見開き外側)にしたい場合は、engine 側で奇偶判定を持ち込む追加改修が必要。

`skip_cover` は内部で1ページ目と2ページ目以降を別々に書き出し `pdfunite`(poppler)で結合している。poppler が無い環境では警告を出して全ページにノンブルが入る。

## 検証時のメモ

- `lib/scan_h3_orphans.py` は、このテンプレートに限らず `### Qn.` 形式の見出しを検出できない(見出しページが `None` になる)。PDF上のテキストが `Q1  zine と…` となり、原稿の `Q1. zine と…` と句点の有無で一致しないため。孤立の確認は画像プレビューで行う
- 原稿側で**太字ラベルと箇条書きの間、引用内の NG/OK 行の間には空行が必要**。空行がないとMarkdownが1段落として解釈し、POINTカードやOKバッジが生成されない
